System Settings

ESP32 connection, alert thresholds and notifications.

ESP32 Connection

Connect directly over the same Wi-Fi network. No Blynk required.

Replace the example IP with the IP shown in Arduino IDE Serial Monitor.
Used in emergency alerts. If your ESP32 sends a helmetId that matches a worker’s Helmet ID, that worker is used automatically.
Your ESP32 and this device must be connected to the same Wi-Fi. The ESP32 must run a web server at /data.

Alert Thresholds

Set these values to match your sensor calibration and project requirements.

These thresholds are evaluated in the browser. They do not change the ESP32 firmware.

Emergency Notifications

When enabled, an emergency shows a notification with the worker’s details and the cause of the emergency.

Notification support depends on your browser permissions.

An on-screen emergency pop-up with the same details always appears, even if browser notifications are blocked.

Data storage

Workers, events, and settings are stored locally in this browser using localStorage.
